# Student Grade Management System 🎓

A Python-based CLI tool to manage student academic records, calculate averages, and track performance.

## ✨ Features
- **Dynamic Grade Calculation:** Automatically calculates the average and determines the performance level (Pass/Good/Excellent).
- **Subject Analysis:** Identifies the "Weakest Subject" for each student.
- **Data Management:** Add, delete, and view student records in a formatted table.
- **Export Capability:** Save the final report to a text file for sharing or printing.

## 🛠️ Concepts Used
- List of Dictionaries for data storage.
- List Comprehension for efficient data deletion.
- Python `statistics` module.
- String formatting for clean CLI tables.
